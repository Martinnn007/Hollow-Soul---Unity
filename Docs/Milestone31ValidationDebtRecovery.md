# Milestone 31: Validation Debt Recovery + Clean Prototype Baseline

## Summary

M31 is a stabilization milestone. It does not add gameplay content. Its job is to make the prototype validation gates match the current intended runtime behavior after the post-M25 branch, reward, equipment, and synergy upgrades.

The main cleanup is forward-compatible validation:

- M14 macro branch checks now allow Isaac-style adjacent door auto-connections instead of requiring the original four hand-authored connection pairs only.
- M15 seeded branch checks validate semantic topology, explicit ports, connectivity, and boss endpoint rules instead of a brittle historical connection count.
- M17 feature branch checks validate the treasure-room role and reward behavior without requiring treasure rooms to remain leaves after adjacent auto-connections.
- M18 reward validation accepts successor M28/M30 reward pools when they preserve seeded pool behavior and required reward tiers.

## Baseline Rules

- Macro rooms may have additional valid adjacent connections as long as every connection is explicit, duplicate-free, and port-based.
- Boss rooms must remain terminal endpoint rooms with exactly one entrance.
- Secret rooms must remain `Single1x1` when generated by branch-feature rules.
- Current scenes may use successor reward pools if those pools preserve M18 seeded reward compatibility.
- M26 is represented by tests rather than a historical generator/validator pair; M31 records that as part of the baseline instead of silently ignoring it.

M31 should be followed by rerunning the M24 platform QA gate and the M25 vertical-slice lock gate. Missing Windows or Vision Pro build modules may still report `BlockedByEnvironment`; those are environment blocks, not prototype content failures.

- M14, M15, M17, and M18 validators no longer fail because of stale topology or reward-pool assumptions.
- M31 validator passes against the current branch graph, reward pools, and scene wiring.
- M24 dependency audit no longer reports M14/M15/M17/M18 validation failures.
- M25 vertical-slice lock is no longer blocked by stale upstream validation debt.
