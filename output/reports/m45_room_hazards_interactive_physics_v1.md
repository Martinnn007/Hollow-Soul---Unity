# M45 Room Hazards + Interactive Physics V1

- Spikes: `1` damage, `0.85s` target cooldown.
- Barrels: `1` HP; standard barrels block movement/projectiles and may drop `1` coin at `12%`.
- Explosive barrels: `1.8m` radius, `2` enemy damage, `1` player damage, boss multiplier `0.5`.
- Starter/origin rooms clear hazards at runtime, so branch starters remain safe.
